# Contributing / Участие в разработке

Thank you for helping PEREKUP! / Спасибо за помощь проекту ПЕРЕКУП!

## Before contributing / Перед участием
- Review [README.md](README.md), [ROADMAP.md](ROADMAP.md), and [SECURITY.md](SECURITY.md).
- For major changes, discuss the idea in an Issue first. Keep changes narrow, testable, and easy to review.
- Use a separate branch and open a Pull Request into `main`. **Do not push directly to main.**
- Describe what changed, what game version you tested, how to reproduce results, and any limitations.
- If you use an AI assistant, review generated content carefully; do not claim untested mechanics work.
- Do not include private data, API credentials, copyrighted vehicle models/textures/screenshots you cannot redistribute, or malware.
- Keep implementation offline-friendly and avoid unnecessary dependencies.

## Project boundaries / Границы проекта
- The mod **does not distribute base-game or third-party car/map assets**.
- No paid gameplay advantages; future donations are voluntary.
- First scope: stock map **East Coast USA**, USD, local profiles, dynamic vehicle catalogs and basic trading.
- Do not silently add cloud services, analytics, or remote code execution.
- New languages, vehicle adapters, narrative jobs and maps should be optional modules.

## Pull Request checklist
- [ ] Change is narrowly scoped, with an Issue or clear rationale.
- [ ] I checked the diff for passwords, private data and accidentally included files.
- [ ] I own or have permission for any included code, assets and translations.
- [ ] I explained tests run, including manual BeamNG.drive testing if possible.
- [ ] I described any AI assistance relevant to reviewing the contribution.
- [ ] No new network calls, telemetry or permissions without explicit review.

## Bug reports / Ошибки
Include the game version, mod version/commit, steps to reproduce, expected vs actual behavior and a sanitized log if needed. Never paste system secrets or personal identifiers.
