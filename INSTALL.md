# Установка и проверка PEREKUP v0.0.1

## Сборка ZIP

Из корня репозитория выполните:

```powershell
python tools/build_mod.py
```

Готовый мод появится в `dist/perekup-v0.0.1.zip`. Архив содержит только папки `lua/`, `scripts/` и `ui/`; автомобили и другие ресурсы BeamNG или сторонних авторов в него не входят.

## Установка в BeamNG.drive

1. Скопируйте ZIP в папку `mods` активной пользовательской папки BeamNG.drive. Обычно активная папка показывается в Launcher → Manage User Folder.
2. Включите PEREKUP в Mods Manager и перезапустите игру, если интерфейс или Lua-расширение ещё не появились.
3. Загрузите **Free Roam → East Coast USA**.
4. Откройте меню `Esc` → **UI Apps**, добавьте **PEREKUP Career**. Если приложения нет в списке, закройте и заново откройте выбор приложений; затем проверьте, что архив включён и внутри ZIP сразу видны `lua/`, `scripts/`, `ui/`.
5. Для новой карьеры выберите одну из трёх доступных конфигураций разных машин. Каталог моделей и конфигураций берётся из установленной игры и активных модов; если вариантов меньше трёх, будут показаны доступные.

## Проверка игрового цикла

1. Убедитесь, что новая карьера показывает баланс **$500**, стартовую машину и объявления.
2. Купите доступное объявление. Баланс должен уменьшиться, а автомобиль появиться в гараже.
3. Попробуйте купить то же объявление повторно и нажать ремонт второй раз: повторная операция должна быть отклонена без списания денег.
4. Выполните ремонт за **$75**, выставьте машину и нажмите продажу. Проверьте баланс и историю.
5. Перейдите к следующему дню: список объявлений должен обновиться.
6. Закройте игру, запустите её снова и нажмите **Продолжить карьеру**. Проверьте баланс, гараж и историю.
7. При отключении мода автомобиля запись о владении должна остаться в гараже с пометкой о временной недоступности.

Сохранение находится в `settings/perekup_career.json` активной пользовательской папки, резервная копия — `settings/perekup_career.json.bak`. Сохранение создаётся только в папке игры и не включается в ZIP.

## API и проверка совместимости

UI App, Free Roam UI Apps, модуль Lua extension и обмен между UI и Game Engine Lua собраны по [официальным инструкциям BeamNG по UI Apps](https://documentation.beamng.com/modding/ui/app_creation/), [Lua extensions](https://documentation.beamng.com/modding/programming/extensions/) и [между Lua/UI VM](https://documentation.beamng.com/modding/programming/virtualmachines/). ZIP использует корневые папки мода из [официального правила упаковки](https://documentation.beamng.com/modding/mod-support/mod_packing/).

Каталог конфигураций подключён через внутренние GE-функции `core_vehicles.getModelList(true)` и `core_vehicles.getConfigList(true)`, которые описаны в [ответе команды BeamNG на форуме моддеров](https://www.beamng.com/threads/how-do-i-spawn-a-random-vehicle-using-lua.72847/). Подробного контракта этих внутренних списков в официальной API-справке нет, поэтому адаптер проверяет наличие функций и форму результата и показывает ошибку каталога вместо подстановки захардкоженных машин. Текущую версию BeamNG нужно подтвердить ручным запуском на целевом ПК.

## Границы этой сборки

Каркас реализует офлайн UI App, каталог из игры, выбор стартовой машины, баланс, рынок, гараж, один базовый ремонт, продажу, дни, историю сделок и локальное сохранение с проверкой чтения и резервной копией. Цены условные.

Покупка пока записывает машину в гаражную карьеру и не создаёт физический автомобиль в мире; ремонт не изменяет повреждения физической машины. Эта интеграция намеренно отложена до проверки точного API загрузки и управления конфигурацией в установленной версии BeamNG. Карта не запускается модом автоматически: сначала нужно открыть East Coast USA через Free Roam, затем добавить UI App. Не проверяйте сборку как готовый релиз, пока не пройдены пункты выше в самом движке.

## Автоматические проверки

```powershell
python -m pip install -r requirements-test.txt
python tools/run_tests.py
```

Lua-тесты запускают чистую бизнес-логику в Lua 5.1 через Lupa. Они проверяют правила экономики, дублирующиеся операции, сохранения и восстановление из копии, но не заменяют проверку в BeamNG.drive.
