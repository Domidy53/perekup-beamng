# Установка и проверка PEREKUP v0.0.1

## Сборка ZIP

Из корня репозитория выполните:

```powershell
python tools/build_mod.py
```

Готовый мод появится в `dist/perekup-v0.0.1.zip`. Архив содержит только папки `lua/`, `scripts/` и `ui/`; автомобили и другие ресурсы BeamNG или сторонних авторов в него не входят.

## Установка в BeamNG.drive

1. Скопируйте ZIP в папку `mods` активной пользовательской папки BeamNG.drive. Обычно активная папка показывается в Launcher → Manage User Folder.
2. Включите PEREKUP в Mods Manager и перезапустите игру, если интерфейс или Lua-расширение ещё не появились.
3. Загрузите **Free Roam → East Coast USA**.
4. Откройте меню `Esc` → **UI Apps**, добавьте **PEREKUP Career**. Если приложения нет в списке, закройте и заново откройте выбор приложений; затем проверьте, что архив включён и внутри ZIP сразу видны `lua/`, `scripts/`, `ui/`.
5. Для новой карьеры выберите одну из трёх доступных конфигураций разных машин. Каталог моделей и конфигураций берётся из установленной игры и активных модов; если вариантов меньше трёх, будут показаны доступные.

## Проверка игрового цикла

1. Начните карьеру: баланс должен быть **$500**, выбранная машина должна появиться в мире и быть передана игроку.
2. Верните стартовую машину в гараж и выставьте её на продажу. Продажа машины, пока игровой объект находится в мире, должна блокироваться.
3. Купите доступное объявление: покупка создаёт запись в гараже. Нажмите **Вывести в мир**, чтобы создать отдельный физический автомобиль.
4. Для ремонта оставьте машину в мире и нажмите **Физический сброс**. До подтверждения игрового объекта деньги не списываются; повторный ремонт блокируется. Если подтверждение задерживается, запрос повторяется, а баланс остаётся неизменным; если объект исчезнет, операция отменится без списания.
5. После ремонта верните автомобиль в гараж, выставьте и продайте его. Проверьте баланс и историю. Повторная покупка, ремонт и продажа одной операции не должны давать повторный доход.
6. Перейдите к следующему дню: список объявлений должен обновиться. Закройте и запустите игру снова, нажмите **Продолжить карьеру**, проверьте баланс, гараж и историю.
7. При отключении автомобильного мода запись о владении должна остаться в гараже с пометкой о временной недоступности.

Сохранение находится в `settings/perekup_career.json` активной пользовательской папки, резервная копия — `settings/perekup_career.json.bak`. Сохранение создаётся только в папке игры и не включается в ZIP.

## API и проверка совместимости

UI App, Free Roam UI Apps, модуль Lua extension и обмен между UI и Game Engine Lua собраны по [официальным инструкциям BeamNG по UI Apps](https://documentation.beamng.com/modding/ui/app_creation/), [Lua extensions](https://documentation.beamng.com/modding/programming/extensions/) и [между Lua/UI VM](https://documentation.beamng.com/modding/programming/virtualmachines/). ZIP использует корневые папки мода из [официального правила упаковки](https://documentation.beamng.com/modding/mod-support/mod_packing/).

Каталог конфигураций подключён через внутренние GE-функции `core_vehicles.getModelList(true)` и `core_vehicles.getConfigList(true)`, приведённые в [ответе команды BeamNG на форуме моддеров](https://www.beamng.com/threads/how-do-i-spawn-a-random-vehicle-using-lua.72847/). Физический объект создаётся отдельным адаптером через `core_vehicles.spawnNewVehicle`; его форма сверена с [открытым примером RLS Career Overhaul](https://github.com/RLS-Modding/rls_career_overhaul/blob/4db9ea9b19d02202c033c9d494d4020b01ab87a0/lua/ge/extensions/overhaul/career/business/fleet/garage.lua). Подробный официальный контракт этих игровых функций не опубликован, поэтому каждый вызов проверяется на наличие и успешный результат. Финальную совместимость нужно подтвердить на целевом ПК.

Экономика использует `Value`, мощность, массу и класс конфигурации, если они доступны. В [официальной справке по конфигурациям](https://documentation.beamng.com/modding/vehicle/tutorials/configs/) `Value` назван ценой автомобиля, но указан как поле, используемое для сортировки конфигураций в селекторе; поэтому это только базовый игровой ориентир, не подтверждённая рыночная или MSRP-цена. Остальные цены и состояние — расчёты карьеры, ограниченные разумными диапазонами. В правом верхнем углу приложения можно выбрать русский или английский; выбор хранится в настройках UI App.

Ремонт отправляется в Lua VM физического автомобиля. После подтверждённого `onReset` объект выполняет `requestReset(RESET_PHYSICS)` и, если доступно, `resetBrokenFlexMesh()`. Такой ремонт полностью сбрасывает физическое состояние машины, а не чинит отдельные детали. Callback `onReset` предусмотрен [официальной документацией по vehicle-specific Lua bindings](https://documentation.beamng.com/modding/input/vehicle-specific-bindings/); вызовы reset сверены с [открытым примером RLS Career Overhaul](https://github.com/RLS-Modding/rls_career_overhaul/blob/4db9ea9b19d02202c033c9d494d4020b01ab87a0/lua/ge/extensions/overhaul/career/economy/cheats.lua). Это проверенные примеры, а не гарантия неизменного внутреннего API.

## Границы этой сборки

Карьерный баланс, история, предложения, оценка состояния и экономические операции сохраняются локально с резервной копией. Стартовый и купленный автомобили создаются в мире как игровые объекты; связь записи карьеры с игровым ID действует в текущей сессии. Купленные машины появляются по отдельной команде из гаража. Перед продажей их нужно вернуть в гараж.

Процент состояния и стоимость на рынке пока являются оценками карьеры. В стандартном модовом API не найден подтверждённый Lua-контракт для чтения фактического повреждения машины, поэтому мод не выдаёт оценку за телеметрию BeamNG и не сохраняет физические повреждения между игровыми сессиями. Полный физический сброс меняет реальный игровой объект, но не ремонтирует его по деталям. Полная проверка связки spawn/reset/callback и нескольких автомобилей должна пройти на стационарном ПК с актуальной BeamNG.drive. Карта автоматически не запускается: сначала откройте East Coast USA через Free Roam, затем добавьте UI App.

## Автоматические проверки

```powershell
python -m pip install -r requirements-test.txt
python tools/run_tests.py
```

Lua-тесты запускают бизнес-логику и имитацию границ игровых объектов в Lua 5.1 через Lupa. Они проверяют каталог, экономику, появление и возврат объекта, блокировку операций с машиной в мире, ожидающий callback ремонта, отмену при потере объекта, восстановление незавершённого ремонта, повторные операции и сохранения. Это статические проверки интеграционного контракта; они не запускают BeamNG и не заменяют проверку в игре.
